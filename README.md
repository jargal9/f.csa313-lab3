## SLO ба Error Budget тооцоо

| Сценарио | SLI (Хэмжих зүйл) | Босго (Threshold) | Цонх / Нөхцөл |
| :--- | :--- | :--- | :--- |
| **Performance** | `/cart/add` latency | p(95) < 200 мс | 20 VU тогтмол, 1 мин |
| **Reliability** | `/pay` error rate | rate < 8% | 20 VU, 1 мин |
| **Availability** | Бүх хүсэлтийн амжилтын хувь | rate > 90% | 10с зогсолт орсон, 2 мин |

* **Босго сонгосон үндэслэл:** Серверт үндсэн 5% алдаа суулгасан тул reliability босгыг 8% гэдэг нь бодитой сонголт юм. Локал орчинд `/cart/add` маш хурдан ажилладаг тул k6 дээрх threshold-той уялдаж p(95) < 200 мс байхаар авлаа.
* **Error Budget тооцоо:** 2 минутын (120 секунд) цонхонд 90% availability гэдэг нь 10%-ийн алдах эрх буюу 12 секундийн "эвдрэх эрх"-ийг цагаар илэрхийлж байна. (Харин k6 дээр хүсэлтээр тооцоход сервер унасан үед connection refused буцаж, хүлээлт байхгүй болдог тул хүсэлтийн давтамж түр зуур өөрчлөгддөг).
